# Weird library components

This library includes a set of custom PCB components for KiCad V10.

## Short-mass probe testpoint

In order to facilitate the use of your oscilloscope short-mass probe, this double
testpoints includes a hole for your probe tip, and a smaller diameter hole for your
short-mass wire.

## Cutaway jumpers

The cutaway closed jumpers have a copper track with a soldermask opening, so it’s easier
to cut this track with a cutter. Then the jumpers turn into a "standard" footprint if you
need to add a 0 ohm resistor or a solderball or jumper poles.

## PCB art color picker

A PCB component with different areas, with silkscreen, soldermask, and copper clearance, to
give an overview of all the PCB shades and transparences you can get with your stackup.

## Breadboard area

A breadboard area, to place in your board if you have some extra space.
